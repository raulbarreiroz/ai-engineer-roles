# Data Processing Addendum (excerpt)

## 1. Roles

Client is the data controller. Provider acts as a processor only for Personal Data processed on Client's documented instructions.

## 2. Subprocessors

Provider may engage subprocessors listed in Annex A. Provider will give Client **ten (10) business days** notice before adding a new subprocessor, during which Client may object on reasonable grounds.

## 3. Security

Provider maintains encryption in transit (TLS 1.2+) and at rest for production datastores, access logging, and annual penetration testing.

## 4. Breach notice

Provider will notify Client without undue delay and no later than **seventy-two (72) hours** after becoming aware of a Personal Data Breach affecting Client data.

## 5. Deletion

Upon termination, Provider will delete or return Personal Data within **thirty (30) days**, except where retention is required by law.
