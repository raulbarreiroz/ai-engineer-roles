# AI Engineer - Semi Senior

## Definition
Entrena modelos desde cero con PyTorch/TensorFlow, optimiza hiperparámetros, aplica técnicas de data augmentation y despliega modelos en producción (MLOps básico: monitoreo, versionado).

## Specific Project
Sistema RAG (Recuperación + Generación) que responde preguntas sobre documentación legal interna, usando embeddings locales (all-MiniLM-L6-v2) y vector DB (Chroma), con un LLM fine-tuneado con LoRA.

## Core Concepts
LangChain / LlamaIndex (retrievers, chains), Vector DB (cosine similarity, HNSW), chunking y overlapping, Fine-tuning con LoRA/QLoRA (PEFT), MLflow para tracking de experimentos, cuantización dinámica (bitsandbytes).

## Recommended Modern Technologies
LangGraph (agentes con ciclos) o LlamaIndex, Ollama, Qdrant o Weaviate, Unsloth, Ray, BentoML.
