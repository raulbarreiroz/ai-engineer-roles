# AI Engineer - Senior

## Definition
Diseña sistemas complejos de IA (arquitecturas RAG, agentes autónomos, LLMs), escala la inferencia (cuantización, paralelismo), implementa entrenamiento distribuido y audita la ética, sesgos y explicabilidad del sistema.

## Specific Project
Plataforma multi-agente donde un agente planificador, uno ejecutor y uno crítico colaboran para generar y validar código Python a partir de instrucciones en lenguaje natural, desplegado con vLLM.

## Core Concepts
Multi-agent systems (AutoGen / CrewAI), vLLM (PagedAttention y continuous batching), cuantización GPTQ/AWAV/GGUF, MLOps (Kubeflow / KServe para inferencia serverless), Evaluación automática (RAGAS, DeepEval), Guardrails (NeMo / Guardrails AI), monitoreo de drift (prompt y data drift).

## Recommended Modern Technologies
vLLM, SGLang, AutoGen / CrewAI, NVIDIA Triton, Argilla, Guardrails AI, Ray Train + DeepSpeed.
